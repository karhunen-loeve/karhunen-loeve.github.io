images · signals · the transforms between them

At night I see transformations. Some of them are still useful in the morning.

What I care about is the change of basis. Fourier, wavelet, Radon, Hough: each one lifts a picture off the grid it happened to be sampled on and drops it somewhere the structure you were after is a single bright coefficient instead of ten thousand faint ones. A straight edge. A periodic texture. A point source sitting a hair below the resolution limit. Different transforms, one idea: do the work in the domain where the question is easy, then come back.

The rest is making it survive contact with code. Rust now, C++ before it. I want the type of a value to say what the value means: which grid, which units, which curve it has already been through. Then the compiler objects on the line where the mistake happens, not a reviewer three months later.
